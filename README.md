Check out the world model that predicts upcoming cyber attacks before they actually occur so that they can be avoided in the future. 
To run the model in StreamLit, clone the repository, look out for the Dataset cic.csv in the release and in the terminal with the path as your repository, run this command:
" python src/train.py --epochs 10 --batch_size 128 " ;
" streamlit run src/app.py "
